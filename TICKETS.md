# Обращения

Ниже обращения от пользователей и коллег. Запуск и тестовые данные описаны в [README](README.md).

1. Пользователь dave пишет, что ссылка активации из письма не работает: страница грузится бесконечно.

   ```bash
   curl -X POST localhost:3000/api/auth/activate/stale-token
   ```

2. По итогам внешнего аудита: через эндпоинт снимка холста (`/api/canvas/shape/snapshot`) пользователь смог увидеть фигуры холста, к которому у него нет доступа.

3. Пользователи жалуются, что массовое изменение фигур подвисает. Время ответа заметно растёт с размером пакета, а когда двое одновременно редактируют один холст, второй ждёт, пока завершится запрос первого. Даже пакет из одного действия отвечает не быстрее чем за полсекунды. Замерить можно скриптом из раздела [«API»](README.md#api).
